# Student Daily Expense Tracker

A Java application that collects a student's daily budget and expenses, calculates the total expense, remaining or exceeded amount, and displays the budget status.

## Features
- Accepts student name, daily budget, and expenses using Scanner
- Calculates total expense
- Calculates remaining amount
- Calculates exceeded amount when the budget is crossed
- Checks whether expenses are within budget
- Displays: Within Budget, Budget Fully Used, or Budget Exceeded
- Prevents negative budget and expense values
- Displays a complete daily expense report

## Concepts Used
- Class and Object
- Instance Variables
- Methods and Return Types
- Scanner
- Arithmetic Operations
- If-Else Conditions
